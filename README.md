# НейроИскра / NeuroSpark

Рабочее название. Оно меняется в массиве TITLE в начале App.tsx.

## Быстро попробовать

Откройте NeuroSpark.html в полноценном браузере. Это автономная сборка: React, стили и задания уже внутри, установка и интернет не нужны. Просмотрщик HTML внутри мессенджера может не выполнять JavaScript — тогда откройте файл именно в браузере. Сохранение прогресса для локальных HTML зависит от настроек браузера.

## Запустить исходники

Понадобится Node.js 20.19+ или 22.12+.

1. Распакуйте архив и откройте папку neuro-spark в VS Code.
2. В терминале выполните `npm install`.
3. Выполните `npm run dev` и откройте адрес из терминала.
4. Для готовой веб-сборки выполните `npm run build`. Результат — папка dist.

Основные запрошенные файлы: App.tsx, App.css, package.json. Дополнительный index.html нужен как точка входа Vite. При переносе в существующий React-проект импортируйте App как обычный компонент. App.tsx сам не вызывает createRoot, поэтому двойного монтирования не будет.

## Правила

- 60 секунд на раунд; третья ошибка сразу завершает игру.
- Ровно четыре ответа на вопрос; один правильный.
- Одна подсказка на весь раунд, время при её использовании не останавливается.
- Верный ответ — одно очко. Четыре уровня доступны сразу: простой, средний, сложный, продвинутый. Три верных ответа подряд повышают сложность в пределах выбранного уровня; ошибка сбрасывает серию. Выбранный уровень сохраняется.
- Задания в пределах раунда не повторяются. Если карточки доступной сложности исчерпаны, открывается следующая сложность.
- После игры доступны объяснения, бытовые примеры, источники и повторение ошибок без таймера.
- В тренировке ошибок нет ограничения по ошибкам и не начисляется общий прогресс.
- Прогресс, рекорд, язык и настройка фуриганы сохраняются в localStorage. Очки начисляются по завершении раунда.
- Игровые ранги: 0 / 10 / 30 / 65 / 110 верных ответов за завершённые раунды.
- Управление клавиатурой: 1–4 — ответ, H — подсказка.

## Содержание

117 карточек: 24 на площади, 40 на развёртки, 28 на проценты и 25 на устный счёт. 40 карточек развёрток используют пять семейств тел, два направления вопроса и повороты схемы. Тексты, варианты, подсказки и разборы есть на русском, английском, японском и упрощённом китайском. Японская фуригана включается отдельно и охватывает основные математические и интерфейсные термины.

Математическая база встроена в App.tsx и не требует сервера. Нейтральные подписи вариантов развёрток не раскрывают правильный ответ. Геометрические рисунки выполнены SVG, пунктир отмечает сгибы. Размеры на рисунках условны, значения из вопроса имеют приоритет.

Мозг — игровая схема с условной подсветкой сетей, а не анатомический атлас, сканирование или оценка IQ. Освещение разных сетей не означает измерение реальной активности или доказанное развитие конкретного участка мозга. Лобные и теменные области взаимодействуют при математических задачах; геометрия и вычисления частично используют пересекающиеся сети.

## Проверки

Успешно выполнены TypeScript strict и production-сборка Vite. Автоматизированная проверка React в DOM-среде подтвердила 117 карточек, четыре уникальных варианта на каждом языке, вычисляемые ответы, смену языков, фуригану, рост сложности, одну подсказку, завершение на третьей ошибке, отсутствие повторов в раунде, тренировку, запись прогресса и истечение времени. Независимая проверка складывания куба и параллелепипеда подтвердила шесть разных направлений граней и согласованные длины рёбер.

Полноценная визуальная проверка в Chromium не выполнена: запуск браузера заблокирован средой исполнения. Мобильная компоновка предусмотрена CSS, но её внешний вид следует проверить на устройстве.


## Обновление: меню, уровни и иллюстрация

Меню содержит «Играть» и «Мои успехи». В успехах видны лучший результат, количество завершённых игровых раундов, общая точность и результаты по четырём темам. Самые сильные темы определяются по лучшей точности среди тем с минимум тремя ответами; при равенстве показываются все. Подробные счётчики собираются с этого обновления: для старых сохранений сохраняются XP и рекорд, а неизвестные прошлые ответы не выдумываются. Повторение ошибок не увеличивает общие счётчики.

Уровни не требуют открытия: простой использует внутренние сложности 1–2, средний — 2–3, сложный — 3–4, продвинутый — 4–5. Внутри выбранного диапазона сложность повышается после серии верных ответов. Когда все карточки диапазона выбранной темы пройдены, раунд завершается без повторения вопросов.

Логотип и иллюстрация мозга теперь выполнены в 2D SVG с градиентами, плавными нейронными связями и мягким свечением. Правильный ответ вызывает короткий световой импульс; настройка уменьшения анимации учитывается. Все элементы встроены в App.tsx и не требуют отдельной картинки. Исправлено положение нижней треугольной грани развёртки призмы; повёрнутые развёртки автоматически помещаются в область рисунка.

Дополнительная автоматизированная проверка подтвердила работу меню, всех четырёх свободно доступных уровней, диапазонов сложности, статистики по темам, лучшей темы, сохранения рекорда и миграции старых данных. 2D-иллюстрация отдельно отрисована и визуально проверена. Полная браузерная проверка компоновки остаётся недоступной в среде исполнения.


## Обновление: волшебные звуки и свечение

Мозг получил цельный силуэт, мягкое объёмное освещение, более выразительные извилины и светящиеся сигналы на связях. В финале раунда все нейроны ненадолго загораются вместе со световой волной. Кнопка «Ещё немного волшебства» повторяет этот момент. При включённой системной настройке уменьшения движения анимация отключается.

Короткие звуки генерируются локально через Web Audio API без MP3, внешних сервисов и загрузки файлов. После трёх верных ответов при фактическом повышении внутренней сложности звучит небольшой перелив; в конце раунда — мягкое пятинотное арпеджио. Ручное завершение раунда не запускает финальный звук. Переключатель «Звук» доступен в меню и во время игры, сохраняет настройку и сразу выключает звучание.

Аудиоконтекст создаётся только после пользовательского нажатия, например «Начать игру». Если браузер не поддерживает Web Audio или не разрешил воспроизведение, игра и визуальное свечение продолжают работать. Скрытая вкладка не запускает новый звуковой эффект. Звук пока не проверен на реальном iPhone: учитывается стандартная политика запуска аудио после нажатия. Рекомендации: https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices

## Card bank and history

270 cards: 40 nets, 24 area/formula cards, 127 mental arithmetic, 79 percentage cards. Each has four languages, four choices, a hint, a worked solution and an application. Unseen eligible cards are prioritised, then the least-seen cards. A card is never repeated within a round.

Answer history starts with this version and stores the latest 3,000 answers in localStorage in the same browser, including practice answers, the use of a hint and the chosen difficulty. Filter it by topic or mistakes. Existing scores are preserved; past individual answers cannot be reconstructed. Browser data deletion clears history. Opening a downloaded file from a new path or another browser may use separate storage.

Arithmetic shortcuts use elementary identities (distributive property and fractions); references: https://openstax.org/books/prealgebra-2e/pages/7-3-distributive-property and https://openstax.org/books/prealgebra-2e/pages/6-1-understand-percent .
